### Архітектурний стиль та діаграма
Для системи обрано трирівневу клієнт-серверну архітектуру, що складається з клієнтської частини (Tailwind CSS), сервера додатків (Python) та бази даних (PostgreSQL). Архітектурна діаграма візуалізує розподіл відповідальності між цими рівнями та їхню взаємодію із зовнішніми сервісами (LiqPay, Нова Пошта) через JSON. Такий підхід забезпечує ізоляцію бізнес-логіки на сервері, гарантує безпеку обробки персональних даних і дозволяє ефективно масштабувати систему.

### ER-діаграма бази даних
На діаграмі зображено концептуальну модель реляційної бази даних онлайн-магазину, що складається з п'яти основних сутностей: «Користувач», «Замовлення», «Товар», «Категорія» та «Позиція_замовлення». Для кожної таблиці визначено первинні ключі (PK) для унікальної ідентифікації записів, зовнішні ключі (FK) для встановлення зв'язків «один-до-багатьох» та відповідні типи даних (VARCHAR, INT, DECIMAL, DATETIME). Ця структура забезпечує цілісність даних та нормалізацію інформації про клієнтів, каталог товарів і транзакції.

### Каркас і макет UX/UI
Надано структурні каркаси (Wireframes) та деталізовані візуальні макети (Mockups) ключових сторінок застосунку GlowBeauty, включаючи головну сторінку, каталог із фільтрами, картку товару, кошик, сторінку оформлення замовлення та особистий кабінет. Інтерфейс спроєктовано з акцентом на зручність користувача (UX), інтуїтивну навігацію та естетичну привабливість (UI). Особливу увагу приділено функціоналу підбору відтінку (Shade Finder) та процесу безпечної оплати.
